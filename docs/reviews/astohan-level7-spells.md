# Заклинания и действия 7-го уровня в «Асстоханских равнинах»

Кампания использует D&D 2014. Проверены классовые списки, которые движок предлагает герою 7-го уровня. У полного заклинателя доступны ячейки I–IV кругов (4/3/3/1), у паладина и следопыта I–II (4/3), у колдуна две ячейки договора IV круга.

## Что доступно

Из 325 разных заклинаний 8 имеют статус полной проверки, у 191 исполняется формализованная часть. Ещё 120 имеют статус `heuristic`, 6 — `ruling-only`. Для последних двух групп движок отказывает до траты ячейки. Один и тот же профиль может входить в списки нескольких классов. ## Выбор и эффект

- У «Волшебной стрелы» игрок назначает цель каждому дротику. При повышении ячейки появляются дополнительные назначения. «Щит» перехватывает только дротики, летящие в его владельца.
- Для «Духовных стражей» перед сотворением выбирают излучение или некротическую энергию. Тип сохраняется в ауре. Замедление движения внутри неё остаётся ограничением. В книге правил тип урона зависит от мировоззрения; в игре сторону выбирает игрок.
- «Страж веры» занимает выбранную точку. При входе врага в радиус 10 футов проверяется спасбросок Ловкости. Урон излучением равен 20 или 10, предел за время действия — 60 нанесённого урона. Время вне боя пока не удаляет область автоматически.
- «Разбудить» тратит действие союзника в пределах 5 футов. Оно снимает сон или действие гипнотического узора с выбранной цели. Узор действует только на тех, кто его видит и восприимчив к очарованию.
- «Ускорение» даёт преимущество на спасброски Ловкости. Вялость при окончании пока не реализована. «Множественное лечащее слово» учитывает прямую видимость при выборе целей.
- Для семи карточек выровнена запись длительности в раундах с длительностью редакции 2014. Для части состояний фактический таймер уже использовал корректное время в секундах.

## Как проверено

| Отдельный прогон | Результат |
| --- | --- |
| Классовые связки в JS | Из 829 сочетаний «класс и заклинание» 491 прошло исполнение, 338 завершились предусмотренным отказом. Один профиль может встречаться у нескольких классов. |
| Подготовленный отряд в Rust | 32 карточки Ильвы и Мирры, 72 случая с вариантами и крайними бросками. 68 исполнений, 4 ожидаемых отказа, сверены типы событий и replay. |
| Презентация заклинаний | У 325 карточек определён профиль. Для 199 исполняемых карточек построены 253 варианта 3D-эффекта из событий применения. В прогоне использованы снаряды, лучи, области, ауры и направленные эффекты. |
| Основной браузерный клиент | «Цветной шарик» ячейкой III круга по учебному голему, подтверждённое попадание и запись 23 урона в хронике. [Снимок после попадания](../images/astohan-level7-chromatic-orb.webp) |

Штатные заклинания Ильвы и Мирры проверялись в Rust на состояниях 7-го уровня. Сверка сопоставляет с JS типы событий и коды ошибок и проверяет воспроизведение результата по событиям. Для распределения дротиков и урона стража отдельные тесты проверяют числа.

На JS проверены классовые связки с двумя крайними бросками и доступными вариантами, оплата ресурса и replay. В отдельном прогоне клиент получает события разрешённых команд, строит 3D-эффекты, обновляет их до середины анимации и освобождает ресурсы. Это проверка построения эффекта. В основном браузерном интерфейсе отдельно проведено применение «Цветного шарика» ячейкой III круга по учебному голему.

| Проверка | Запуск из корня проекта |
| --- | --- |
| Индекс уровня | `node tools/build-astohan-level7-spell-index.mjs` |
| Касты и отказы JS | `node eval/astohan-level7-spell-audit.mjs` |
| Эффекты 3D из событий | `node eval/astohan-level7-spell-visuals.mjs` |
| Состояния и команды для Rust | `node eval/astohan-level7-spell-rust-fixture.mjs tmp/astohan-spell-review/level7-named.json` |
| Проверка в Rust после генерации | `cargo test --manifest-path rust/Cargo.toml --release -p sk-rules --test level7_named -- --include-ignored` |

В действиях проверены экономика хода и реакции, дополнительные атаки, скрытая атака плута, кара паладина, дикая форма, классовые ресурсы и ограничения уровня. Два боя стандартного отряда против нежити и зверей завершены в массовом стенде. Полная серия боёв в этом прогоне не завершена. [Покрытие классовых умений](../rules-coverage.md)
