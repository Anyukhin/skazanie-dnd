## Изменение статусов

- **SEC-01** получил real-HTTP/auth/storage доказательство; прежняя оговорка
  in-memory probe остаётся верной для первого прохода, но уже не описывает
  всю совокупность evidence. Минимальное исправление сохраняет существующий
  свободный `/api/rooms/:code/dice`; ещё один endpoint не нужен.
- **REC-02** разделён: лишний commit открытого голосования подтверждён, а
  двойной сохранённый общий бросок в проверенном сценарии опровергнут. Это
  P2-восстановление клиентского запроса, не равный по последствиям REC-01
  повтор самостоятельной ability check.
- **UI-02** теперь имеет браузерное подтверждение одновременных транспортов.
  Сам факт нескольких путей синхронизации не делает их избыточными: ещё нужно
  проверить, что выбранная оптимизация сохраняет repair и свежие права доступа.

Актуальная очередь отражена в [общей сводке](../10-current-priorities.md).
Эти уточнения не реализуют предложенные исправления.

## Проверки и изоляция

Probes 29/30 прошли на настоящих локальных серверных процессах с временными
сохранениями и пустым LLM-ключом. В 29 проверены same-key replay, чужой actor,
неизвестная карточка и повтор потреблённого roll. В 30 есть same-key контроли
после потерянного ответа, assertions по журналу, ballot, ресурсам и часам.

Браузерный helper получил опциональный `--observations=<путь>` для метаданных
room/SSE. Он не сохраняет тело состояния или cookie. Отдельный lifecycle smoke
подтвердил штатную остановку и удаление временного каталога. После браузерного
наблюдения также проверено отсутствие его процессов и удалены только его
синтетические данные.

Финальный `pnpm verify` прошёл с первого запуска, exit 0:
**5 685 passed, 6 skipped, 0 failed** (13 бюджетных, 5 667 функциональных и
5 MVP-проверок). Server typecheck и production build успешны. Функциональная
часть — 333,653 с, MVP — 109,138 с, Vite — 14,76 с. Это длительности одного
локального прогона, а не сравнение скорости разных срезов.

Прошли syntax checks трёх `.mjs`, lifecycle smoke, assertions согласованности
восьми browser polling-квитанций и `git diff --check`. Проверены 156 локальных
и 480 закреплённых source-ссылок (160 уникальных источников); пропущенных
файлов и недопустимых строк нет. Независимая проверка выводов подтвердила
указанные границы HTTP, браузера и последствий повторного голоса.
