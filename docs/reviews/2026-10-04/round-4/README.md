## Как превратить выводы в небольшие изменения

1. **Изолировать очередь снимков по кампании (REC-04, P2).** Очистка при
   переключении плюс проверка identity перед применением. Версии сравнивать
   только внутри одной кампании. Критерий: URL, экран, cache и следующая
   команда остаются в B при позднем снимке A.
2. **Распространить сохранение ключа на обычное действие (REC-01, P1).**
   Использовать уже работающую модель неизвестного результата тактической
   команды. Сохранять payload и key до подтверждения, отделять явное новое
   действие от восстановления старого. Критерий: backend commit → потеря
   ответа → повтор даёт тот же commit; изменённый ввод не переиспользует ключ.
   Начать с проверенного auto-roll-пути, затем расширять по тестам.
3. **Закрепить границу backup (RCV-05, P2).** Самый небольшой вариант —
   явный режим остановленной записи и проверяемое выполнение этого условия.
   Если нужна работа без остановки, выбрать согласованную границу журнала и
   координацию с writer; повторное чтение одной metadata не доказывает
   согласованность всех файлов. Restore должен отдельно проверять domain
   integrity: аутентификация байтов не заменяет replay-аудит.
4. **Проверять ответ и гарантировать снятие блокировки (REC-03, P2).**
   Небольшой decoder контракта плюс обработка исключений после ответа.
   Ошибка должна оставлять игроку понятный путь восстановления. Не требуется
   новая библиотека валидации или перенос hook целиком в новый state manager.

## Положительные контроли

- Исходное хранилище до и после конкурентного commit здорово; несогласованность
  возникает именно в собранной копии.
- Серверная идемпотентность обычного narrate работает при сохранённом ключе.
  Новый key на стороне клиента — существенная часть воспроизведения.
- Тактический повтор в браузере сохранил ключ и версию; при возврате в A
  использован существующий индикатор неизвестного результата.
- Перезагрузка B после рассинхрона показала правильную комнату. Порча
  серверного сохранения B и отправка следующего действия из неверного экрана
  в этом проходе не установлены.
