# Эмблемы классов

Двенадцать эмблем для шага выбора класса созданы встроенным OpenAI ImageGen
специально для «Сказания». Сторонние изображения и существующие игровые знаки
не использовались: первая эмблема варвара стала только стилевым ориентиром для
остального набора.

Общий визуальный контракт: квадратный тёмно-фэнтезийный герб, кованая бронзовая
рамка, один крупный центральный символ, минимум мелких деталей, отсутствие
текста, логотипов, игральных костей и фирменной амперсанд-эмблемы D&D. Символы:

- варвар — двусторонняя секира;
- бард — лютня;
- жрец — солнечная реликвия;
- друид — дубовый лист с оленьей ветвью;
- воин — меч и щит;
- монах — перевязанный кулак;
- паладин — щит с восходящим солнцем;
- следопыт — лук, стрела и лист;
- плут — кинжал и капля яда;
- чародей — магическое пламя с внутренней искрой;
- колдун — око в разомкнутом кольце договора;
- волшебник — раскрытая книга и восьмиконечная звезда.

Исходники ImageGen сохранены вне репозитория. Production-файлы уменьшены
Lanczos-фильтром до WebP 256×256 с качеством 88 и лежат в
`public/assets/ui/class-icons/`. Хеш и размер каждого файла зарегистрированы в
`data/asset-rights.json`; общий статус реестра `review_required` и блокировка
распространения не меняются.
