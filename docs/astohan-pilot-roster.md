# Пилотные листы Асстохана

В пилоте четыре рецепта уровня 7.

Рецепты находятся в `data/astohan-pilot-builds-v1.json`.

- Воин «Чемпион» с мечом, щитом и арбалетом.
- Варвар «Путь тотемного воина» с секирой.
- Монах «Путь открытой ладони» с боевым посохом.
- Паладин «Клятва мести» с мечом, щитом и «Наложением рук».

Рецепты используют редакцию `dnd_5e_2014`, не выбирают заклинания и перечисляют только действия со статусом `verified`. Проверка в `server/astohan-pilot-builds.mjs` сверяет класс, подкласс, навыки, умения, стартовое снаряжение и статусы действий с существующими каталогами.

## Штатная сборка

1. Создайте «Асстоханские равнины» по правилам 2014 со стартом на 7-м уровне.
2. Выберите готовый лист в мастере персонажа, дайте герою имя и нажмите «Создать героя». Мастер последовательно сохраняет выборы и поднимает уровень штатными командами `SetCharacterChoices` и `LevelUp`.
3. Включите «Групповую инициативу» в настройках кампании. Для первого боя используйте действия из `exposed_actions` выбранного листа. Остальной каталог показывает статус реализации каждой карточки.

`test/astohan-pilot-builds.test.mjs` проверяет переход с первого до седьмого уровня в Rules Engine и replay. `test/astohan-pilot-progression-api.test.mjs` проверяет импорт всех четырёх листов, повышение до 10-го уровня после получения опыта и боевые карточки варвара через обычные команды игрока. Офлайн-стенд `eval/astohan-playthrough.mjs` по умолчанию использует этот состав.
