# Расовые выборы, особенности и снаряжение D&D 5e 2014

Статус: проверена
Создана: 2026-08-31
Обновлена: 2026-08-31
Связано: [`создание героя 2014`](2026-08-30-dnd-2014-character-creation.md), [PR #68](https://github.com/Anyukhin/skazanie-dnd/pull/68)

## 1. Зачем это нужно

Отдельного списка рас недостаточно: персонаж 2014 должен сделать обязательные
расовые выборы, получить их механические последствия и осознанно выбрать
стартовый комплект. Мастер должен показывать результат каждого решения до
создания героя, как отдельная сцена подготовки партии, а не как длинная форма.

## 2. Желаемое поведение

- `speciesChoices` хранит только ID server-owned групп: язык, навыки, инструмент,
  заговор и драконье происхождение.
- `starterEquipmentChoices` хранит только ID классовых групп и вариантов.
- Сервер повторно проверяет количество, принадлежность и ссылки на каталоги.
- Производные владения, врождённая магия, сопротивления и действия выводятся
  из зафиксированного профиля вида.
- Основные особенности первого уровня исполняются общими воронками Rules Engine:
  атака, урон, спасбросок, перемещение, отдых и `UseCombatAction`.
- Мастер разбит на восемь шагов и постоянно показывает справа итог героя.

## 3. Исполняемое покрытие

- Устойчивость к яду дварфа и коренастого полурослика, сопротивление огню
  тифлинга и стихии драконорождённого.
- Дополнительные ОЗ холмового дварфа и отсутствие штрафа скорости дварфа в
  тяжёлом доспехе.
- Везение, Храбрость и Проворство полурослика.
- Наследие фей против магического сна и очарования; Гномья хитрость использует
  ту же контекстную воронку спасброска.
- Непоколебимая стойкость и Свирепые атаки полуорка.
- Оружие дыхания драконорождённого с выбранной областью, спасброском, уроном и
  восстановлением ресурса.
- Врождённые заговоры и открывающиеся по уровню расовые заклинания через
  существующий `CastSpell`.
- Четырёхчасовой Транс эльфа.

## 4. Ограничения

- Тёмное зрение хранится в серверном профиле и листе, но индивидуальная
  серверная модель зрения ещё не отделена от общей раскрытости карты.
- Чувствительность дроу к солнечному свету, Знание камня, Естественная
  скрытность и ремесленные/социальные особенности без общего доменного пути
  остаются структурированными, но не объявляются `verified`.
- Стартовые варианты покрывают исполнимые PHB-комплекты из текущего item
  catalog; наборы без отдельных catalog IDs представлены честными
  `ruling-only` комплектами.
- Вариантный человек и custom background требуют реализованного каталога feats
  и в этот срез не входят.

## 5. Критерии готовности

- [x] Все обязательные группы расовых выборов достижимы в UI и проверяются сервером.
- [x] Выбранные навыки и заговоры доступны в реальном листе и боевом каталоге.
- [x] Основные расовые механики покрыты unit/replay тестами.
- [x] Все 12 классов имеют проверяемые группы стартового снаряжения.
- [x] HTTP import/restart сохраняет те же выборы и предметы.
- [x] UI показывает постоянную сводку, доступный фокус и мобильную раскладку.
- [x] Обновлены integrity/provenance и документация ограничений.
- [ ] Пройдены browser smoke, `pnpm content:verify` и `pnpm verify`.

## 7. Итог реализации

Добавлены восемь групп расовых выборов и 37 классовых групп снаряжения. Новый
import сохраняет policy v2 и выбранные ID; события policy v1 продолжают replay
со старым детерминированным набором и без ретроактивного добавления механик.

Rules Engine исполняет основные особенности через существующие общие функции,
а не через второй расовый контур. `test/species-traits-2014.test.mjs`, HTTP
import/restart, 2747-тестовый основной корпус, отдельный полный MVP, server
typecheck, `pnpm content:verify`, `pnpm rules:verify` и production build прошли
2026-08-31. Первый объединённый запуск получил инфраструктурный `ECONNRESET`
только в длинном MVP; тот же тест сразу повторён отдельно и прошёл полностью.

Browser smoke остаётся ручным: чистая встроенная сессия требует отдельного
разрешения на создание или вход в локальную учётную запись.
