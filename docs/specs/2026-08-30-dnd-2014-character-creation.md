# Создание героя по D&D 5e 2014

Статус: проверена
Создана: 2026-08-30
Обновлена: 2026-08-30
Связано: [`cutover D&D 2014`](2026-08-30-dndsu-2014-ruleset-cutover.md), [PR #68](https://github.com/Anyukhin/skazanie-dnd/pull/68)

## 1. Зачем это нужно

Кампания 2014 не должна открывать мастер происхождения 2024. Выбранная редакция
обязана определять расы, подрасы, источник прибавок характеристик,
предыстории и стартовое снаряжение героя.

## 2. Желаемое поведение

- Каталог создания запрашивается по `ruleset_id`.
- 2024 сохраняет существующие backgrounds и прибавки от предыстории.
- 2014 предлагает 14 вариантов девяти PHB-рас с подрасами и их фиксированными
  прибавками; полуэльф выбирает две дополнительные характеристики.
- 2014 предлагает 13 PHB-предысторий без прибавок характеристик и без origin
  feat; навыки, инструменты, языки и feature выводятся сервером по ID.
- Новый герой 2014 выбирает server-owned варианты классового снаряжения,
  получает предметы предыстории и её стартовое золото.
- Import, reducer и replay используют ruleset кампании и не смешивают каталоги.

## 3. Ограничения

- Основные расовые features первого уровня исполняются общими путями атаки,
  урона, спасброска, движения и отдыха; остаток перечислен в связанной
  [спецификации особенностей](2026-08-31-dnd-2014-racial-traits-and-equipment-choices.md).
- Для предметов используется существующий compatibility-каталог; отсутствующие
  в нём личные вещи представлены одной неисполняемой записью-комплектом.
- Вариантный человек и optional/custom background не входят в первую волну:
  feats в проекте пока имеют статус `missing`.

## 4. Критерии готовности

- [x] Два каталога доступны отдельным HTTP-путём и не смешиваются.
- [x] Сервер отклоняет бонусы не выбранной расы или предыстории.
- [x] Все 14 вариантов рас/подрас и 13 предысторий 2014 достижимы в UI.
- [x] Языки и инструменты 2014 выбираются в пределах server-owned списков.
- [x] Стартовые предметы и золото совпадают после replay/restart.
- [x] Старый сценарий 2024 проходит без изменения результата.
- [x] Пройдены `pnpm rules:verify`, `pnpm content:verify` и `pnpm verify`.
- [ ] Пройден браузерный сценарий 2014 и 2024.

## 5. Проверка

```bash
pnpm rules:verify
pnpm content:verify
pnpm verify
```

## 6. Итог реализации

Добавлены отдельные JSON-каталоги происхождений, предысторий и стартового
снаряжения 2014. `GET /api/rulesets/:id/character-creation` выбирает их по
`ruleset_id`; мастер загружает этот endpoint при входе в кампанию. Import и
reducer повторно проверяют расовые бонусы, выборы предыстории и редакцию
события, а стартовый набор материализуется только после успешного commit.

Дополнение 2026-08-31 добавило обязательные расовые выборы, основные
исполняемые особенности и выбор классового снаряжения вместо единственного
предустановленного варианта.

Автоматическая проверка покрывает реальный HTTP import, отказ от подмены,
идемпотентность, restart/replay, все 12 классов и совместимость сценария 2024.
`pnpm rules:verify`, `pnpm content:verify` и полный `pnpm verify` прошли
2026-08-30. Встроенный браузер подтвердил загрузку локального приложения, но
полный ручной путь обоих мастеров не выполнен: чистая сессия требует отдельного
разрешения на создание/вход в локальную учётную запись.
