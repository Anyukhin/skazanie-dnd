# GLM 5.3 Flash против GPT-5.6 Luna

Дата: 2026-08-30. Стенд: `eval/narrator-craft-eval.mjs`, по два прогона
шести синтетических сцен на модель. Fallback-модели отключены, чтобы ответ
другой модели не маскировал отказ кандидата. Использован фактический таймаут
текущей конфигурации — 20 секунд.

Точный идентификатор взят со страницы RouterAI:
[`z-ai/glm-5.3-flash`](https://routerai.ru/models/z-ai/glm-5.3-flash).
На 2026-08-30 RouterAI указывает контекст 1M, текст, изображения и видео на
входе, текст на выходе, 9 ₽ за 1M входящих и 30 ₽ за 1M выходящих токенов.
Для [`openai/gpt-5.6-luna`](https://routerai.ru/models/openai/gpt-5.6-luna)
указаны контекст 1M, текст, изображения и файлы на входе, 21 ₽ за 1M входящих
и 131 ₽ за 1M выходящих токенов при промпте до 272K. Тарифы могут меняться.

## Совместимость API

RouterAI принимает GLM 5.3 Flash без поля `reasoning` и с effort
`low`/`medium`/`high`, но реальный запрос с `{ enabled: false }` возвращает
ошибку `Reasoning is mandatory for this endpoint and cannot be disabled`.
Поэтому production-профиль задаёт минимальный поддерживаемый режим
`{ effort: 'low' }`. Luna измерялась в своём production-режиме
`{ enabled: false }`.

| --- | ---: | ---: |

| Принятые тексты Рассказчика | 4 из 8 | **6 из 8** |
| Принятые социальные реплики NPC | **4 из 4** | 2 из 4 |
| Все принятые model outputs | **8 из 12** | **8 из 12** |
| Память | **100 % / 100 %** | **100 % / 100 %** |
| Различимость голосов | **100 % / 100 %** | 0 % / 0 % |
| Медиана provider-вызова | **4,46 с** | 16,29 с |
| Максимум | **6,37 с** | 20,01 с |
| Учтённые токены in + out | 19 866 + 1 220 | 11 206 + 2 890 |
| Расчёт по опубликованному тарифу | ≈ **0,22 ₽** | ≥ 0,61 ₽ |

Расчёт Luna — нижняя граница: в usage не попали три вызова, завершившиеся
ошибкой или таймаутом. По цене одного токена GLM Flash дешевле Luna в 2,3 раза
на входе и в 4,4 раза на выходе.

GLM не падала у провайдера, но production guard отклонил половину текстов
Рассказчика. В трёх случаях модель приписала герою новое действие или объявила
реакцию NPC вне разрешённого brief, ещё в одном — преждевременно разрешила
обещание. Механика от этого не пострадала: сервер подставил безопасный
детерминированный текст. У Luna один текст отклонил тот же guard, ещё три
ответа заменены из-за provider failure или таймаута.

## Решение

`z-ai/glm-5.3-flash` добавлена в список моделей и поставлена первой в каскаде
fallback. Исходный замер показал конкретный адрес исправления: модель знает
память и различает голоса, но превращает подтверждённый результат в выдуманный
процесс. Поэтому для неё добавлен отдельный контракт Рассказчика; социальный
контроллер его не получает, поскольку там GLM уже давала 100% голосов.

## Дополнение: строгий контракт Рассказчика

В системном prompt теперь явно разделены три вида данных:

- `visible_events` и `visible_state_changes` разрешают описать только уже
  подтверждённый результат;
- `memory_focus` разрешает напомнить ровно один связанный факт, разговор или
  открытое обещание, но не превращает память в текущее событие;
- `sensory_anchors` разрешают статическую атмосферу без выдуманного источника.

Контракт запрещает описывать процесс проверки, делать героя субъектом нового
действия, добавлять реакцию NPC вне `permitted_npc_reactions`, объявлять
состояние обещанного предмета и связывать разные типы улик. Для обычного исхода
задана форма из одного-двух предложений и финальный checklist перед ответом.

Данные кампании при этом не потеряны. В prompt по-прежнему входят безопасный
`NarrationBrief`, сцена, публичные герои и NPC, отфильтрованная память,
`open_promises`, `recent_interactions`, стиль, сенсорные якоря, NPC-досье,
рекап арки и асинхронная обратная связь прошлого хода. Скрытые данные и
авторитетная механика отсекаются до вызова модели.

В сумме: 12 из 12 model outputs приняты без deterministic fallback; все восемь
текстов Рассказчика прошли авторитетный guard. По опубликованному тарифу
зафиксированные 30 018 входящих и 1 216 выходящих токенов стоят примерно
0,31 ₽ — дороже исходного короткого GLM-прогона, но всё ещё примерно вдвое
дешевле измеренного Luna-прогона.

Тот же финальный prompt проверен на других reasoning:

- `medium`: 11 из 12 ответов, один provider failure, память и голоса 100%;
- `high`: 12 из 12, память и голоса 100%, но максимум 19,51 с и заметного
  улучшения текста нет.

Production-профиль остаётся `low`: он дал лучший баланс качества, устойчивости
и задержки. Для сохранения полного ответа рекомендованный общий таймаут поднят
до 20 секунд; механика при любом таймауте уже сохранена и остаётся безопасной.
