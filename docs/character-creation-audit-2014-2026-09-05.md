# Проверка создания персонажа D&D 2014 — 2026-09-05

Основа: `main` / `bcfe5de`, сверенная с `origin/main` после fetch.
Проверен путь мастер → HTTP ImportCharacter → серверный лист → событие → replay.
Рабочее `storage/` не использовалось; браузерные кампании созданы во временном
каталоге на отдельном сервере без LLM.

## Исправления

- Все три эльфийские подрасы получают пропущенное владение Восприятием.
  У дроу убран автоматически выданный Подземный язык: его можно выбрать
  отдельным источником. Сверено с [эльфами 2014 на dnd.su](https://5e14.dnd.su/race/79-elf/).

- Стиль «Защита» учитывается в КД при надетом доспехе. Кольчуга и щит дают
  воину с этим стилем КД 19. Снятие доспеха убирает бонус. Формулировка
  сверена с [Basic Rules 2014, Classes](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/classes#FightingStyle).
- Дыхание белого, серебряного и зелёного драконорождённого требует спасброска
  Телосложения; остальные семь наследий — Ловкости. Сверено с
  [таблицей наследия](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/races#DragonbornTraits).
- Повторяющиеся навыки расы, класса и предыстории заменяются выбранными
  свободными навыками. Сервер проверяет количество и отсутствие уже известных
  владений; выбор хранится в `backgroundChoices.replacementSkills`. Старые
  документы без поля читаются без принудительного изменения. При смене
  классовых выборов исчезнувший повтор не оставляет лишнего владения.
  Основание — [Proficiencies](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/personality-and-background#Proficiencies).
- Новый сетевой импорт отклоняет язык предыстории, уже известный от расы.
  Мастер исключает такие языки из начального и случайного выбора; старые
  события сохраняют возможность replay.
- Мастер предлагает подкласс на первом уровне жрецу, чародею и колдуну и
  передаёт выбранное название существующему серверному валидатору.
  Автоматическое исполнение всех особенностей подкласса этим не добавлено.
- Паладин и следопыт больше не обозначены как имеющие магию на первом уровне.
  Подсказка о последующей магии учитывает зависимость от класса/подкласса;
  вскрытие замков убрано из описания навыка «Ловкость рук».
- Все 14 карточек рас имеют портрет: девять базовых рас и отдельный дроу.
  Промпты и происхождение — `species-portrait-prompts.json`.

## Что проверяют исполняемые тесты

Итоговый `pnpm verify` завершился с кодом 0: 3004 функциональных теста,
отдельные tactical-map budget и полный MVP-сценарий, проверка типов сервера
и production build. `pnpm compendium:verify` и `pnpm content:verify` также
прошли. В сборке остаётся предупреждение Vite о размере основного JS-чанка.

| Область | Проверка |
| --- | --- |
| Комбинации каталога | 14 рас × 12 классов × 13 предысторий = 2184 сборки с фиксированными допустимыми вариантами, сохранением числа навыков и отсутствием повторяющихся языков |
| Характеристики | Стандартный массив, расовые прибавки, два свободных повышения полуэльфа, отказ при чужом профиле и неверной скорости |
| Классы | Классовые навыки, доступные выборы первого уровня, выбранный подкласс при его доступности, известные заклинания |
| Производные числа | Модификаторы, спасброски, ОЗ, КД, скорость, бонус мастерства; стиль «Защита» с доспехом и без него |
| Снаряжение | Серверная материализация классовых и фоновых наборов, альтернативы и отказ при неизвестном варианте |
| Расовые особенности | Дыхание и его ресурс, сопротивления, Везение, Храбрость, Проворство, Стойкость, Свирепые атаки, Транс |
| Сохранение и права | Два игрока заполняют свои места через HTTP, чужой герой недоступен; идемпотентность и replay; новые замены навыков проходят Rules Engine и replay |

Матрица не перебирает все сочетания подклассов, заклинаний, распределений массива
и стартовых предметов. Она проверяет совместимость каталога, а не доказывает
исполнение каждого правила книг.

В браузере созданы два героя: холмовой дварф-воин/солдат и высший эльф-волшебник/
мудрец. Проверены приглашение, отдельное место второго игрока, недоступность
чужого героя, расовый заговор, книга из шести заклинаний и подготовка четырёх
при Интеллекте 16, сохранение и восстановление после перезапуска сервера.
После исправлений отдельно создан жрец-дроу/прислужник: сохранён Домен жизни,
два повторяющихся навыка заменены Магией и Скрытностью. До выбора замены
мастер останавливал переход с объяснением; повторный Эльфийский язык
недоступен, Подземный доступен как дополнительный. Портрет дроу загружен.

## Оставшиеся границы

Полной реализации создания по всем правилам D&D 2014 пока нет:

- Доступен только стандартный массив; броски 4к6 и покупка характеристик,
  вариантный человек, черты, мультикласс и custom background отсутствуют.
  Стандартный массив — допустимый вариант
  [правил создания](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/step-by-step-characters#3DetermineAbilityScores).
- Классовый каталог содержит дополнения эпохи 2014, а не только PHB.
  Многие особенности и дополнительные выборы подклассов не исполняются:
  сохранение названия подкласса не гарантирует полный набор его преимуществ.
- Мастер не предоставляет полный выбор классовых инструментов и отдельную
  замену повторяющихся инструментальных владений. Замена навыков реализована
  отдельно; расширять это утверждение на инструменты нельзя.
- Магия ограничена текущими исполнимыми/частичными карточками; полный список
  книжных заклинаний и все исключения подклассов этим аудитом не реализованы.
- Наборы снаряжения предлагают ограниченные варианты; совместимые item IDs
  пока происходят из каталога SRD 5.2.1. Личные вещи предыстории могут быть
  описательным комплектом; это не завершение cutover предметов.
- Не все расовые и фоновые особенности автоматизированы. Подробности
  сохраняются в `known-limitations.md`.

Добавленный справочник из архива также остаётся `data_only`: он не закрывает
эти пробелы и не включает автоматически новые механики.
