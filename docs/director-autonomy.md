# Режиссёр и завершение сцены

Режиссёр предлагает bounded `DirectorIntent`; сервер авторизует его и не
принимает текст модели за доказательство успеха. Ритм арки может предложить
угрозу, исследование, разговор или встречу, но количество beats не закрывает
квест и не запускает обязательный бой.

Для развязки без боя используется `resolve_scene` с одним из значений:
`negotiation`, `objective`, `decision`. Это только типизированное предложение.
Оркестратор обязан проверить соответствующую цель, переговоры или реальное
решение группы и записать `SceneResolutionRecorded` со `status: confirmed`.
Только такая запись (либо подтверждённый исход встречи) удовлетворяет
`campaignArcClimaxSatisfied`; затем `end_scene` может перейти к следующей сцене.

Старые события и сохранения остаются валидными: отсутствие
`scene_resolutions` трактуется как пустой список, а прежний подтверждённый
боевой исход продолжает удовлетворять условию развязки.
