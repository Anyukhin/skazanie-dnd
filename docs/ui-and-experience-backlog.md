# Бэклог интерфейса и игрового опыта

Составлено по ревью от 2026-07-30, переписано 2026-07-31 после первой волны.
Цель — хороший вечер с друзьями: удалённо, каждый за ноутбуком, голос в
Discord, ведущий — LLM.

Здесь только **невыполненное**. Закрытые задачи из списка убраны, но **номера
оставшихся не менялись**: на них ссылаются цепочки зависимостей, комментарии в
коде и `docs/known-limitations.md`. Пропуски в нумерации — это сделанное.

Принятые решения, из которых собран список:

- эффекты — читаемость плюс лёгкая зрелищность, без системы частиц;
- палитра и поведение эффектов различаются **по школам магии**;
- первым чинить **невидимую тактику**, а не зрелищность;
- главная боль в бою — «непонятно, что происходит»;
- verifier Рассказчика уходит в настройку, качество вытягиваем силой одиночной генерации;
- длинная игра — цепочка арок одними героями;
- владельцу стола нужен минимальный набор инструментов ведущего;
- «Тон / Темы / Границы контента» должны реально соблюдаться;
- NPC получают фишки на доске, меню глаголов и диалоговое окно; в бою остаются
  и уязвимы; в первой версии стоят на постах.

Оценки трудоёмкости: **S** — до дня, **M** — несколько дней, **L** — неделя и больше.

## Как параллелить

Девять потоков. Главное правило: **у каждого файла один владелец**. Поток
правит свои файлы свободно, к чужим — только через согласованный интерфейс.

| Поток | Задачи | Владеет файлами |
|---|---|---|
| 1. Тактическая доска | 4, 6–10, 12, 13 | `src/board-render.ts`, `src/tactical-map-client.ts`, canvas-слой `TacticalBoard.tsx` |
| 2. Эффекты заклинаний | 14–24 | `src/spell-effects.ts` (новый), `src/combat-animation.ts` |
| 3. Панели и HUD | 27, 28, 31–35, 37–43 | `src/App.tsx`, `src/InventoryViews.tsx` |
| 4. Нарратив | 47–52 | `server/narrator.mjs`, `server/llm-client.mjs`, `prompts/`, `eval/` |
| 5. Темп и транспорт | 55 | SSE-часть `server/index.mjs`, `src/useGameSession.ts` |
| 6. Свободный текст | 56–61 | `server/intent-parser.mjs`, `server/action-adjudicator.mjs`, `server/free-action-adjudication.mjs` |
| 7. Кампания и стол | 63–65 | `server/campaign-*.mjs` |
| 8. NPC на сервере | 66–72 | `server/npc-social.mjs`, `server/prop-placement.mjs`, `server/tactical-map.mjs` |
| 9. Награды и контент | 73–77 | `server/loot-tables.mjs`, `server/merchant-economy.mjs`, `data/` |

### Узкие места

поэтому поток 2 работает в **новом** файле `src/spell-effects.ts` и

## Поток 6. Свободный текст

Свободное действие проходит через bounded `ActionAdjudicator`: модель может
предложить только разрешённые цель, предмет, навык, владение и тип последствия,
после чего сервер повторно связывает их с текущей сценой, листом и инвентарём.
Без модели работает тот же детерминированный контракт. СЛ, бросок, событие и
последствие всегда выбирает и применяет сервер.

- [x] **56. Расширить `ActionAdjudicator`.** Он уже вызывает LLM и выбирает
      характеристику, навык и риск из перечислений
      ([`server/action-adjudicator.mjs:96`](../server/action-adjudicator.mjs)) —
      добавить в его выход цель действия, задействованный предмет, применимое
      владение и тип последствия. Границы безопасности не меняются: СЛ и бросок
      остаются за сервером. Закрыто контрактом `action_adjudicator/v2`; значения
      модели повторно проверяются по authoritative state. **L**
- [x] **57. Учитывать владение навыком.** «Прячусь за телегой» сейчас даёт
      Ловкость СЛ 15 с `proficient: false` — владение Скрытностью

## Поток 7. Кампания и стол

- [x] **68. Задел под движение.** Позиция — событие с самого начала
