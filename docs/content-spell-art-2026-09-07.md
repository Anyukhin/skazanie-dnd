# Исправленные иконки заклинаний

Четыре изображения созданы встроенным ImageGen. Итоговые PNG размещены в
`public/assets/ui/action-icons/`, уменьшены штатным System.Drawing до 256×256
с сохранением альфа-канала и зарегистрированы в `data/asset-rights.json`.
Исходные генерации сохранены отдельно; промежуточные варианты с нарисованной
«шахматной» подложкой в игру не включены.

Общий промпт выбранных новых иконок:

> Create a single fantasy game spell inventory icon on a transparent background.
> Detailed hand-painted fantasy inventory art. Square canvas, centered isolated
> subject, margin around the complete subject, no cropping. Export a transparent
> PNG cutout with an alpha channel. Outside the subject is fully transparent,
> no white-gray checkerboard pattern. No text, no watermark, no frame. This icon
> is layered over an existing game UI background.
