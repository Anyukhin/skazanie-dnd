# Следующая партия сложных материальных компонентов

Дата исследования: 21 сентября 2026 года. Это исследование следующего шага
после component foundation. Оно не меняет `data/`, сервер и статусы заклинаний.
Из 13 записей с `components.material.unresolved` выбраны три кандидата, у
которых материальное требование можно закрыть существующим matcher-ом
`spell_ids` + `value_cp`, без нового обработчика компонентов.

## Кандидаты

| ID | Что проверено на карточке dnd.su | Расходование | Почему это небольшой следующий шаг |
|---|---|---|---|
| `augury` | В, С, М: особые палочки, костяшки или фигурки с отметинами стоимостью не менее 25 зм. Каст 1 минута, ритуал, на себя. | Карточка не говорит, что компонент расходуется. По правилу 2014 это постоянный предмет. | Один предмет, одна цена, нет количества и смешанного набора. Повторные применения до продолжительного отдыха имеют отдельное правило случайного ответа, но оно относится к эффекту, а не к инвентарю. |
| `clairvoyance` | В, С, М: фокусировка стоимостью не менее 100 зм — украшенный камнями рог для слуха или стеклянный глаз для зрения. При создании выбирается зрение или слух; затем режим можно менять действием. | Карточка не говорит о расходовании. | Два взаимоисключающих каталожных предмета с одной ценой и одним `spell_id`; оба уже укладываются в OR-поиск `spell_ids`. Связь выбранного сенсорного режима с видом фокуса остаётся отдельной частичной механикой. |
| `scrying` | В, С, М: фокусировка стоимостью не менее 1000 зм — хрустальный шар, серебряное зеркало или чаша со святой водой. Каст 10 минут, концентрация до 10 минут. | Карточка не говорит о расходовании. | Три альтернативных предмета с одной ценой, без количества и без расходуемой части. Спасбросок, 24-часовой запрет на повтор после успеха и сенсор — отдельная механика заклинания. |

Источники компонентов и взаимодействия:

- [Гадание / Augury на dnd.su](https://www.dnd.su/spells/40-augury/) — строка
  «Компоненты» и ограничение повторных применений.
- [Подсматривание / Clairvoyance на dnd.su](https://www.dnd.su/spells/238-clairvoyance/)
  — строка «Компоненты», выбор зрения/слуха и пояснение о двух фокусировках.
- [Наблюдение / Scrying на dnd.su](https://www.dnd.su/spells/176-scrying/) —
  строка «Компоненты», варианты цели, спасбросок, сенсор и 24-часовой запрет
  после успешного спасброска.
- [Basic Rules 2014, Material (D&D Beyond)](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/spellcasting)
  — компонент с указанной стоимостью должен быть конкретным предметом;
  расходование требуется только когда это прямо сказано в описании заклинания.

Таким образом, для всех трёх `consumed` должно оставаться `false`. Сумма в
кошельке, имя предмета или обычная сумка компонентов не заменяют конкретный
фокус с указанной стоимостью. Это следует из правил 2014 и не является
предположением о поведении карточки.

## Минимальный контракт реализации

Схему `componentsSchemaVersion` расширять не требуется. Для трёх строк
`data/dndsu-spells-0-6.json` следующий генератор должен:

```json
"material": {
  "description": "...из карточки dnd.su...",
  "costGp": 25,
  "consumed": false,
  "focusSubstitutable": false
}
```

Аналогично используются значения `100` и `1000`; поля `unresolved` и
`requirementNote` после успешной проверки строки удаляются. В каталоге
`SPELL_MATERIAL_COMPONENTS` добавляются записи через уже существующий
`spellMaterialEntry`:

```text
srd_5_2_1:material-augury-divination-tools-25gp
srd_5_2_1:material-clairvoyance-listening-horn-100gp
srd_5_2_1:material-clairvoyance-glass-eye-100gp
srd_5_2_1:material-scrying-crystal-orb-1000gp
srd_5_2_1:material-scrying-silver-mirror-1000gp
srd_5_2_1:material-scrying-holy-water-basin-1000gp
```

Каждая запись получает `material_component: { kind, value_cp, spell_ids }`;
`spell_ids` содержит ровно соответствующий ID, `value_cp` равен 2 500,
10 000 или 100 000. Все эти вещи неэкипируемы и нестакаемы, как текущие
дорогие материальные компоненты. Текущий `spellMaterialItemFor` уже принимает
любую запись с нужным `spell_id` и минимальной стоимостью, а
`spellComponentCostEvents` не создаёт `ItemConsumed`, потому что
`consumed: false`.

Для `clairvoyance` и `scrying` это только компонентный слой: на первом шаге
любой из перечисленных допустимых фокусов открывает cast, а выбранный режим
сенсора не выводится из названия вещи. Если нужен источник-верный режим
«рог = слух / глаз = зрение» или отдельный выбор варианта для `scrying`, это
должно быть следующей опцией spell command и проверяться тем же matcher-ом по
`kind`; подмена этого ограничения описанием предмета недопустима. В этой
записке такой runtime-слой не объявляется сделанным.

## Приёмка для будущей реализации

Для каждого из трёх ID нужны одинаковые проверки:

1. Без соответствующего каталожного предмета cast отклоняется с
   `SPELL_MATERIAL_COMPONENT_REQUIRED`; ячейка, эффект и инвентарь не
   изменяются.
2. Подходящий предмет минимальной стоимости разрешает cast при наличии руки;
   после успешного cast его количество не меняется и `ItemConsumed` отсутствует.
3. Предмет меньшей стоимости, монеты без предмета, произвольное имя и предмет
   с чужим `spell_ids` отклоняются.
4. При занятых обеих руках отказ имеет код
   `SPELL_MATERIAL_HAND_REQUIRED`; при одной свободной руке cast разрешается
   по уже существующему правилу V/S/M.
5. Для `clairvoyance` принимается отдельно рог и отдельно глаз; для `scrying`
   отдельно шар, зеркало и чаша. Один предмет не должен удовлетворять другому
   заклинанию только из-за одинаковой стоимости.
6. Повтор с тем же `idempotency_key`, replay и restart сохраняют предмет и не
   создают расходование. У `augury` отдельным тестом фиксируется, что повторный
   каст может перейти в случайное знамение, но это не уменьшает компонент.
7. Полная механика сенсора и эффекта остаётся `heuristic` до отдельной работы;
   добавление компонентов не повышает статус до `verified`.

Остальные десять unresolved-наборов (`protection-from-evil-and-good`,
`warding-bond`, `magic-circle`, `galder-s-speedy-courier`,
`leomund-s-secret-chest`, `legend-lore`, `magic-jar`, `find-the-path`,
`create-homunculus`, `create-undead`) требуют либо альтернатив с разным
составом, либо количества/пары предметов, либо частичного расходования и
поэтому не входят в этот малый шаг.
