пилота. Остальные 176 принятых файлов лежат в рабочих каталогах и тестовой
выгрузке. Полный manifest на 532 ID ещё не пересобирался.

## Как продолжить

1. Продолжать только ID из `checkpoint.json → missing_ids`.
2. Не перегенерировать `completed_ids`.
3. Незавершённые raw-файлы сначала отдельно нормализовать и проверить; при
   сомнительной анатомии, лишних пальцах, псевдотексте, слипшихся деталях или
   невозможной геометрии — отклонить и перегенерировать.
4. После 532/532 запустить `tmp/icon-all/finalize_icons.py` без `--install`,
   просмотреть все крупные и 32-pixel контакт-листы.
5. Только после полного semantic QA выполнить установку через `--install`,
   `pnpm icons:manifest`, обновить `data/asset-rights.json`, затем запустить
   `pnpm content:verify` и `pnpm verify`.
