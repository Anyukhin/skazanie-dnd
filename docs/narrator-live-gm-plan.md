# Рассказчик как живой ведущий — план волны

Цель владельца (2026-10-10): чтобы ИИ-ведущий ощущался как живой человек за
столом; общая оценка «как живого ведущего» — больше 7, лучше 8.

## Как меряем

- `node eval/gm-session.mjs` — одна и та же партия в своём мире («Серый
  Причал»: пустой баркас, культ, маяк), проигранная через HTTP так, как её
  играл человек 2026-10-10: личная зацепка героя, обыск, подкуп, вопрос
  ведущему, творческое заклинание, отыгрыш без механики, переход к маяку,
  ночь, короткий бой. Судьи: по ходам (`openai/gpt-6-luna`, рубрика
  «живой ведущий» 1–10) и общий (`anthropic/claude-sonnet-5.5`, 1–10 по
  языку, отклику, уликам, NPC, связности мира, предысториям, бою и общему
  впечатлению). Без модели — счёт служебных фраз и повторов. Один прогон
  ≈6–7 ₽ (≈3.5 ₽ — общий судья).
- `node eval/astohan-playthrough.mjs --live --judge` — широкий прогон авторской
  кампании ботами (тупики, согласованность, бой).
- Выводы — только по парам прогонов (модель шумит).

| Служебный текст в ответах | 73 % | 65 % |

Главные причины (разбор кода 2026-10-10):

1. **Служебные шаблоны вместо голоса ведущего.** Разбивка на шаги
   («В заявке 2 последовательных шага…»), «К кому именно подойти?» для
   предметов, «Не совсем понял…» на отыгрыш, «Вышло: <пересказ заявки>»,
   «Назовите конкретного участника», «Дорога ведёт весь отряд…», «Этого вы
   пока не знаете…», карточки бросков. Рассказчик делает одну попытку: любое
   срабатывание проверки текста — и в хронику идёт шаблон.
2. **Улики ходят по кругу.** Удачная проверка открывает ближайшую заготовку, а
   не ответ на заданный вопрос; ни один путь не может ответить на мелкий
   вопрос («чья метка на борту»); NPC знают все находки отряда, повторяют
   одни и те же фразы, отказывают без встречной зацепки.
3. **Мир расходится с рассказом.** Старт всегда 08:00 при заказанной «ночи,
   грозе»; отряд стоит на краю города, а не в таверне пролога; «Старый маяк»
   строится дорогой с рекой; слова «подхожу к баркасу» фишку не двигают.
4. **Предыстории героев** не доходят ни до рассказчика, ни до NPC, ни до
   Режиссёра; в мире нет зацепок, связанных с героями.
5. **Бой — журнал «Система боя»**: один шаблон на событие, слова игрока к
   действию теряются, критическая реплика может пропасть или прийти после хода
   врага, «Мирель стабилизирован», «спасброски от смерти» у монстра.

- Итог замеров 10–14: общая оценка 3–5 (среднее ≈3.5), по ходам 4.2–5.2;
  тренда вверх нет. Каждая партия вскрывает новый хвост запасных строк и
  частных сбоев, и починка одного места не поднимает общее впечатление.
  Что судья называет каждый раз: (1) расследование не движется — NPC
  противоречат друг другу о ключевых фактах (чья лодка), повторяют одну
  улику, игроки не идут по зацепкам, засада из случайных зверей и гоблинов
  не связана с культом, обещанное (огонь маяка) не случается; (2) ключевые
  творческие ходы — иллюзия, реплика у воды — получают одну строку без
  последствий; (3) бой — пересказ журнала. Первое — уровень сюжета и стенда
  (заскриптованные игроки, встреча из генератора), а не голоса рассказчика.

- Главная претензия судьи в замерах 10–11 — «стена отказов»: проваленный
  осмотр и наблюдение ничего не давали, хотя заготовки лежали рядом. Ответ —
  правило «Многократные проверки» (DMG 2014, гл. 8): вне спешки обыск —
  тщательный, провал броска стоит получаса, а спрятанное находится (или
  честно установлено, что его нет). С замера 12 — для любого обыска вне
  опасности, не только «методичного».
- Стенд с замера 12: ожидание у маяка — до двери, без «ждём темноты»;
  ходы 11–13 не сравнимы с прежними.

  Разброс оценки по ходам между прогонами одного кода — до ±0.5; общий
  судья шесть замеров подряд держится на 2–3.

  Сравнение замеров 3+ с базой — с оговоркой: стенд стал честнее к ведущему
