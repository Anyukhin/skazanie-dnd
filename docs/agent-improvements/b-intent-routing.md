# Трек B. Маршрутизация свободного текста игрока

Дата: 2026-10-01. Повод — живой провал: «Иду в таверну «Морской Змей»
расспрашивать о сыне Финна» стало проверкой Убеждения вместо перехода сцены.
Причина общая: когда детерминированные распознаватели промахивались, реплика
доходила до судьи свободных действий, а у его контракта (v6) не было способа
сказать «это переход / разговор / непонятно» — только назначить проверку.

## Таксономия: какие маршруты есть в коде

Реплика проходит те же шаги, что в `/api/narrate`:

| Шаг | Код | Маршрут |
| --- | --- | --- |
| вид реплики | `inferRequestKind` (`server/intent-parser.mjs`) | `question` → ответ ведущего без хода; `discussion` → реплика стола |
| уход и бросок судьбы | `proposeAgentInteraction` → `detectPartyExitRequest` (`server/player-request-router.mjs`, `server/party-exit-intent.mjs`) | `travel_exit` → карточка решения отряда или соло-переход |
| лор, видимая сцена, «куда идти» | `answerKnownLore` | `question` |
| несколько шагов | `actionSequence` | `multi_step` → уточнение первого шага |
| намерение | `IntentParser.parse` | `social`, `attack`, `cast_spell`, `ability_check`, `rest`, `other_rule` |
| свободное действие | `handleUnknownAction` (`server/autonomous-orchestrator.mjs`) | `move_in_scene` (`MoveActor` к названному собеседнику), иначе `free_action` → `ActionAdjudicator` (модель) |

Эталонный класс реплики и допустимые маршруты (`GOLD_ROUTES` в
`eval/intent-routing-eval-2026-10-01.mjs`):

| Класс | Правильный маршрут |
| --- | --- |
| `travel_exit` — уйти из локации, пойти в названное место карты | `travel_exit` |
| `move_in_scene` — шаг внутри сцены | `move_in_scene` или `free_action` (главное — не уход) |
| `social_talk` — разговор с присутствующим | `social` |
| `trade` — торговля текстом | `social` (механическая покупка — карточка торговца) |
| `ability_check` | `ability_check` |
| `attack`, `cast_spell`, `rest`, `multi_step` | одноимённый |
| `ask_gm_question` | `question` |
| `ooc_party_chat` — реплика стола, вне игры | `discussion` |
| `free_action_improv` — импровизация в сцене | `free_action` |

## Метод

- **Основной набор** — `eval/intent-routing-cases-2026-10-01.json`, 136 реплик
  (первое/второе/множественное лицо, падежи названий, «», "" , цель-инфинитив,
  ловушки внутри сцены, опечатки, короткие фразы, сегодняшние провалы). Написан
  **до** правок. Одна правка эталона после замера BEFORE: `c06` «Взламываю замок
  сундука» — `free_action`, а не `ability_check`, потому что замок контейнера
  исполняет команда пропса на пути свободного действия; BEFORE пересчитан с
  исправленным эталоном.
- **Отложенный набор** — `eval/intent-routing-holdout-2026-10-01.json`, 48
  реплик, написан после правок, но до их прогона на нём, для подбора шаблонов
  не использовался. Основной набор после правок — оценка «на обучающих данных»;
  честная оценка обобщения — отложенный.
- Фикстура: отряд в таверне «Ржавый Якорь» (Аквилон), на карте мира 12 точек
  (одна скрытая), в сцене Старый Финн, Марта, Борис, торговка Ильса.
- Детерминированный прогон без сети: `node eval/intent-routing-eval-2026-10-01.mjs --output …`.
  BEFORE — копия `server/` с HEAD-версиями трёх модулей разбора плюс
  незакоммиченными правками лида в `party-exit-intent.mjs`
  (`INTENT_ROUTING_ROOT=<копия>`).
- Живой прогон: реплики, которые хоть в одном из состояний (BEFORE ∪ AFTER)
  доходят до судьи, через настоящий `ActionAdjudicator` на `openai/gpt-6-luna`
  с `reasoning: { enabled: false }`; v6 и v7 — один и тот же модуль, v6
  подаётся текстом (`systemPrompt`), так что разница только в промпте.
  Ожидаемый маршрут судьи: `travel` для ухода (засчитывается, только если
  карточка действительно откроется), `talk` для разговора и торговли, `clarify`
  для вопроса и реплики стола, `check` для остального.

## Что изменено

- `server/party-exit-intent.mjs` — слова места стали целыми словами с падежным
  окончанием (раньше `лес\w*` = «начинается с „лес“», т.к. `\w` в JS — латиница);
  новые глаголы (`покидаем`, `выхожу`, `едем`, `двигаемся`, `добираемся до`,
  `вернуться`, `пошли`…); предлог «до»; цель-инфинитив перед местом; прямые и
  английские кавычки; шаг к углу/стойке/человеку перевешивает место, если назван
  раньше него; существительные на «-ть» не обрывают название («в старую
  крепость»). Новое: `exitContextFromState` (известные точки карты и имена
  присутствующих; скрытые точки не попадают), `detectPartyExitRequest(text,
  context)` узнаёт точку карты по имени в любом падеже (тот же критерий, что у
  `scene-architect.mjs`), `announcesMovement`, `travelDestinationIsPlace`,
  уход одним глаголом («Уходим.»).
- `server/player-request-router.mjs` — карточка ухода получает контекст карты;
  `proposeRoutedTravel` — карточка по маршруту судьи; речевые глаголы не уводят
  в справку о лоре; `action_adjudicator/v7` в `PLAYER_REQUEST_ROLES`.
- `server/intent-parser.mjs` — исправлен `DIRECT_QUESTION_PATTERN`; вопрос по
  форме (вопросительное слово + «?», без «ты/вы» и без вопроса о знаниях героя);
  маркеры вне игры, обращение к отряду; предложение пойти куда-то — заявка;
  глаголы разговора и торговли; Внимательность и поиск только в личных формах
  (инфинитив «обыскать/изучить сундук» остаётся команде пропса); заклинание
  раньше лечения, «колдую»; передышка — отдых; удар по неживому — не атака;
  проверка Обмана/Убеждения по целым словам («вручаю», «долгую», «склоняюсь»).
- `prompts/action_adjudicator/v7.txt` (v6 сохранён) — поле `route`
  (`check|travel|talk|clarify`), `destination`, `npc_hint`; правила маршрута.
- `server/action-adjudicator.mjs` — грузит v7; `route` необязателен (нет —
  значит `check`, ответ формы v6 допустим), выдуманное значение — сломанный
  ответ и детерминированный разбор; `destination` очищается от разметки и
  ограничен 80 знаками; `npc_hint` — только id присутствующего NPC из брифа.
- `server/autonomous-orchestrator.mjs` — `routedFreeAction` в
  `handleUnknownAction`: `travel` → `kind: 'route_travel'` без коммита и
  подсказка до `takeRouteHint`; `talk`/`clarify` → уточнение без проверки. Не
  срабатывает в бою (кроме `clarify`), на повторе исполненной заявки и на ответе
  игрока на уточнение (иначе «да» возвращало бы тот же вопрос по кругу).
- `server/index.mjs` — минимальный крюк после `gameOrchestrator.handle`: при
  `free_action_outcome === 'route_travel'` открывается обычная карточка решения
  отряда (`request_party_decision`). Голосование открывается и в соло: переход,
  понятый моделью, игрок подтверждает сам. Правка `game-orchestrator.mjs` не
  понадобилась — подсказка передаётся через `takeRouteHint`, а не через ответ.
- `server/prompt-descriptors.mjs`, `test/security.test.mjs`, `AGENTS.md`,
  `README.md`, `docs/known-limitations.md` — v6 → v7.
- Тест `test/intent-routing.test.mjs`; замер `eval/intent-routing-*`.

## Ограничения

- Шаблоны — словари: новые глаголы и формы по-прежнему могут промахнуться;
  отложенный набор это показывает (85 %, а не 98 %). Промах теперь ловит v7.
- «Снимаем комнату и ложимся спать до утра», «Садимся отдохнуть» остаются
  судье: `Adjudicator` выбирает долгий отдых по слову «долг», и сон «до утра»
  стал бы коротким отдыхом; «отдохнуть» — команда пропса (кровать).
- Обращение к герою-соседу по имени («Торвальд, …») без «ты со мной?» не
  отличить от обращения к NPC: `inferRequestKind` вызывается без состояния.
- «Предлагаю Марте монету за сведения» уходит в реплику стола («предлагаю»).
- Карточка по маршруту судьи открывается только если назначение прошло словарь
  мест (родовое слово или известная точка карты); иначе игрок получает
  подсказку, как заявить уход явно.
- Маршрут `talk` не открывает разговор сам: социальный путь живёт в
  `GameOrchestrator`, поэтому игроку предлагается обратиться к собеседнику
  прямо («Марта, …»). Торговка из `merchants` в участники брифа судьи не
  попадает, и `npc_hint` на неё не указывает.
- Крюк в `server/index.mjs` (карточка по `route_travel`) HTTP-тестом не покрыт:
  корпус тестов запускает сервер без ключа, и судья там модель не зовёт. Покрыты
  его части — `proposeRoutedTravel` и `routedFreeAction`/`takeRouteHint` через
  `GameOrchestrator`; живой путь нужно проверить в браузере.
- `scene-architect.mjs` и `party-exit-intent.mjs` держат по своей копии
  критерия «то же слово в другом падеже». Общий модуль — отдельная задача
  (`scene-architect.mjs` вне этого трека).
- `classifyNpcSocialCheck` (`server/npc-social-check.mjs`, вне трека) всё ещё
  сравнивает подстроки; разбор намерения перепроверяет его по целым словам, но
  `buildNpcSocialCheckPolicy` в том же модуле — нет: в разговоре с NPC «вручаю»
  и «долгую» по-прежнему дают проверку Обмана.
