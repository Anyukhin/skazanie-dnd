# Ведущий «как живой»: как продолжать работу

Передача работы на другой компьютер (2026-10-12). Здесь всё, что нужно, чтобы
продолжить улучшать ИИ-ведущего без прежней переписки: цель, решения
владельца, как мерить, что уже сделано, что сломано и куда смотреть в коде.
Подробный журнал замеров и обоснования — `docs/narrator-live-gm-plan.md`;
общие правила репозитория — `AGENTS.md` (читать первым).

## 1. Цель и решения владельца

- **Цель** — общая оценка «как живой ведущий» выше 7 из 10 (лучше 8) у
  общего судьи `eval/gm-session.mjs` (`anthropic/claude-sonnet-5.5`). Сейчас
  плато 3–4: замеры 15–33 дают 2–4, по ходам 4.5–5.2.
- **Модель рассказчика — GPT-6 Luna** (`openai/gpt-6-luna`), не Sol: решение
  владельца. Летописец (пролог, хроника арки) — `openai/gpt-6.1-sol` через
  `DND_AI_LORE_MODEL`, ему дан срок 45 с.
- **Архитектуру рассказчика можно менять** ради качества ответа.
- **Привала после победы без заявки нет.**
- **Меньше замеров, больше смены подхода** (2026-10-12): один прогон после
  пакета правок, искать решения у других (статьи, разборы), а не чинить по
  одному сбою.
- **В бою слова ведущего — на ключевые моменты** и когда игрок сам описал
  поступок словами; обычный удар без слов — строка боя. Игроку, который
  отыгрывает, не должны приходить сухие цифры.
- Бюджет LLM — до 50 ₽ за вечер игры. Игра — удалённо через Discord, экран
  от 1080p, лучше 1440p.

## 2. Настройка на новом компьютере

1. `git clone https://github.com/Anyukhin/skazanie-dnd.git`, ветка `main`.
   Работать в отдельной ветке `claude/<тема>` от `main`, возврат — через PR.
2. Node `>=20.19.0`, `corepack enable`, `pnpm install`.
3. `.env` в корне (в git не попадает) — по образцу `.env.example`. Для замеров
   нужны (значения — только у владельца, в репозиторий и в логи не писать):

   | Переменная | Что ставить |
   | --- | --- |
   | `ROUTERAI_BASE_URL` | `https://ohmylama.ru/v1` (провайдер замеров) |
   | `ROUTERAI_API_KEY` | ключ OhMyLama |
   | `DND_AI_MODEL` | `openai/gpt-6-luna` |
   | `DND_AI_FALLBACK_MODELS` | `google/gemini-2.5-flash,deepseek/deepseek-v4-flash` |
   | `DND_AI_LORE_MODEL` | `openai/gpt-6.1-sol` |
   | `DND_AI_MODEL_TIMEOUT_MS` / `DND_AI_PROBE_TIMEOUT_MS` / `DND_AI_FAILURE_COOLDOWN_MS` | `20000` / `15000` / `120000` |
   | `DND_AI_MAX_TOKENS` | `1200` |
   | `DND_MAP_LIBRARY` | `off` (замеры на процедурных картах) |

4. Проверка: `node --test test/narrator.test.mjs` и
   `node node_modules/typescript/bin/tsc --noEmit -p tsconfig.server.json`.

Игровой сервер владельца живёт в Docker на порту 8787 — не трогать. Замер
поднимает свой сервер на свободном порту и временном хранилище сам.

## 3. Как мерить

```bash
node eval/gm-session.mjs --out tmp/gm-session/m34-1
```

- Партия двух героев (Мирель — волшебница, ищет сестру Илу; Борин — воин,
  когда-то смолчал о ночных лодках) в мире, который создаёт модель: причал,
  пустой баркас, маяк, культ. 19 ходов: разговоры, обыск, заклинание на NPC,
  переход к маяку, наблюдение, дверь, засада, бой словами, «продолжим», обыск
  тел. Около 15 минут.
- Флаги: `--offline` (без модели — проверить сам сценарий), `--no-judge`,
  `--keep` (оставить хранилище с трассами), `--rejudge <каталог>`
  (пересудить готовую стенограмму), `--holistic-model <id>`.
- Итог в `<out>/`: `report.md` (оценки, главные проблемы, «исправить
  первым»), `transcript.md` (вся партия), `report.json` (ходы и ответы),
  `narrator-diagnostics.json`, `server.log`.
- **Как читать диагностику.** «Отбракованные черновики» — в основном штатные
  строки команд (`deterministic-mechanics`: конец хода, удар кнопкой), это не
  брак. Настоящий брак — записи с `violations` (код проверки) и
  `deterministic-provider-fallback` (провайдер не ответил). «Спасённые
  правкой» — черновики, которые проверка отклонила, а правка исправила.
- Разброс одного кода между прогонами — до ±1 в общей оценке и ±0.5 по
  ходам. Вывод о подходе — по паре прогонов или по стенограмме, не по одной
  цифре.
- Учёт расхода показывает ≈0 ₽: OhMyLama не отдаёт цену. Реальная цена — в
  кабинете провайдера.
- OhMyLama бывает недоступна минутами: тогда мир — шаблонный «Ривермарк» или
  его пишет Gemini. Такой прогон недействителен — смотреть начало
  `transcript.md` и `server.log`.

## 4. Что сделано (ветка `claude/narrator-live-gm`, слита в `main`)

Журнал по замерам — `docs/narrator-live-gm-plan.md`, раздел «Журнал» и
«Подходы из чужих работ». Коротко по слоям:

- **Провайдер.** Каскад моделей OhMyLama; одиночный тайм-аут или 5xx после
  успеха не снимает Luna; содержательные ошибки (битый JSON) — без
  остывания; Gemini без `presence_penalty` и `json_schema`. Создание мира —
  120 с и повтор при недоступности провайдера.
- **Мир и канон.** Канон сцены (`scene_canon`) от автора кампании знают
  рассказчик, NPC и судья заявок; путь к новому месту — короткий; отряд
  входит в постройку снаружи.
- **Что видит рассказчик.** Сводка поля `field` (кто где, под крышей ли,
  состояние словами, кто рядом; враги — только на раскрытых клетках);
  карточка `now` последним блоком запроса; незнакомого NPC зовёт по роли
  (`known_by_name: false`).
- **Ответ рассказчика.** План ответа (`narratorResponsePlan`): на реплику
  героя — одна новая деталь места (`new_element`); отклонённый проверкой
  черновик получает одну правку с перечнем нарушений (Self-Refine) в том же
  сроке, иначе — запасной текст.
- **Бой.** Сцена вместо строки — гибель и падение героя (с зовом к
  товарищу), поверженный враг, бегство, сдача, критический удар героя или по
  герою, ход со словами игрока; поражение без смертей — сцена; вводка
  схватки знает, что герой сделал только что. Чистка служебных строк
  (награда, начало боя, добыча, голосование).
- **NPC.** Ответ без повтора: сверка по основам слов с репликами NPC, соседей
  и находками отряда, повторная попытка с перечнем повторённого; давние
  ответы приходят модели сутью (`npc_reply_gist`); «цена — один раз»; людей
  вне `leads` не называет.
- **Разбор заявок.** Обращение по имени и падежу, уход по двум репликам,
  закрытый список известных мест (`known_places`) у судьи; вход в постройку,
  которая — другое место карты мира, открывает решение отряда о пути туда;
  составная заявка (скрытность + наблюдение) не отнимает видимого.
- **Карта.** Якоря «причал» и «лодка»; якоря автора кампании доходят до
  первой карты (раньше терялись при двойной нормализации).

## 5. Что сломано и что делать дальше (по замеру 33)

По порядку пользы. Источник — `tmp/gm-session/m33-1/` на прежнем компьютере;
суть переписана здесь.

1. **NPC повторил вопрос вместо ответа.** Борин: «кто тут деньгами сорит?» —
   Вея: «…Кто сорит деньгами?». Похоже, фильтр повторов
   (`freshReplyText` в `server/npc-social-controller.mjs`) вырезал ответ
   как пересказ и оставил эхо вопроса. Нужно: если после вырезки остался
   только вопрос, перекликающийся с вопросом игрока, — повторная попытка
   или ответ из `leads`/`speakable_facts`, а не эхо.
2. **Вводка схватки не знает исхода.** `just_happened` — только текст
   заявки («толкает дверь и входит внутрь»), и модель написала «внутри
   маяка», хотя дверь не поддалась. Передавать и последний ответ ведущего
   (`renderEncounterOpening` в `server/creative-director.mjs`, вызов в
   `server/index.mjs` у `EncounterAssembler`).
3. **Формулы в бою.** «Падает и больше не поднимается» ×3, «остаётся рядом с
   Мирель и Борином» (выросло из `field.next_to`). Идея: мягкая правка, если
   в ответе есть пять слов подряд из последних трёх ответов; `next_to` не
   пересказывать (строка в стиле момента или убрать из брифа момента).
4. **Взгляды NPC на разговор героев между собой** («Тома хмурится, а Вея
   следит») — почти в каждом ответе. Для реплики своему отряду не давать
   `permitted_npc_reactions` вовсе (`narrationNpcReactions(..., { heroDeed })`
   в `server/game-orchestrator.mjs`), оставить только `new_element`.
5. **Добыча:** «Культист 1 —Скимитар; Культист 3 —Скимитар…» — сгруппировать
   одинаковое («у каждого по скимитару»), пробел после тире
   (`server/free-action-adjudication.mjs`, ответ обыска тел).
6. **Мелкий разнобой мира:** «крики чаек» ночью в грозу (сенсорные якоря
   гавани не знают времени суток), «мокрая трава» на скале у маяка
   (материал зоны карты маяка — трава).
7. **Общий судья в каждом прогоне** называет три вещи: связность места и
   времени, содержательность NPC (новая деталь в каждом ответе), живость
   боя. Числа по ходам растут медленно; прыжок к 7 вряд ли даст ещё одна
   частная починка — нужен подход: например, сервер собирает для каждого
   ответа «что нового узнаёт игрок» (зацепка, деталь, решение) и проверяет,
   что это прозвучало.

Идеи на будущее по картам (ролик о WFC, youtube `fIIdPk49wsY`): перестройка
одной зоны вместо всей карты — для недостающего якоря и для ведущего;
вода под лодкой у причала. Полный переход на WFC не нужен: гарантии карты
(выход, досягаемость, посты) держат генераторы и `map-quality`.

## 7. Грабли

- `server/game-orchestrator.mjs` хранит **смешанные окончания строк** (CRLF и
  LF). Скрипт, который читает файл и пишет обратно с одним окончанием,
  превращает правку в три тысячи строк диффа. Править инструментом, который
  меняет только нужные строки, и смотреть `git diff --stat` перед коммитом.
- В Bash heredoc без кавычек съедает обратные слэши в регулярках
  (`\s` → `s`). Скрипты правок с регулярками — отдельным файлом.
- Прежде чем менять проверку или правило, искать тест, который его
  закрепляет: несколько тестов держат прежние решения (например, «один вызов
  рассказчика» — теперь «не больше одной правки»).
- Полный корпус: `node tools/run-test-suite.mjs` (~6370 тестов, несколько
  минут). Точечно: `node --test test/<файл>.test.mjs`.
- «Без CI» — `[skip ci]` в заголовке коммита и в заголовке merge-коммита PR.

## 8. Источники подходов

- FIREBALL — Zhu и др., 2023, arXiv 2305.01528: рассказ по состоянию игры.
- Lost in the Middle — Liu и др., 2023, arXiv 2307.03172: середина длинного
  контекста читается хуже.
- Learning to Break the Loop — Xu и др., 2022, arXiv 2206.02369: повтор в
  контексте самоподкрепляется.
- Self-Refine — Madaan и др., 2023, arXiv 2303.17651: правка по своему же
  черновику и замечаниям.
- Процедурные подземелья на WFC — youtube `fIIdPk49wsY`: обязательные куски
  сначала, остальное вокруг; локальная перестройка; перебор сидов.
