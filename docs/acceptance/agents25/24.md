# Исполнитель 24: 2D/3D, анимационные семьи и смысловые коллизии

Дата проверки: 2026-09-22. Базовая ревизия: `c4e570921edea08f8952edef7c437bc5c9182ab3`.

## Граница доказательства

Я прочитал все 439 строк каталога `data/dndsu-spells-0-6.json` и сопоставил их с
`spell25-presentation-current.json`. Это проверка инвентаря и семантики по
описаниям D&D 2014/dnd.su, а не заявление, что 439 заклинаний отрендерены и
просмотрены. Отчёт координатора показывает 164 настроенных visual profiles и 43
группы с совпадающей полной сигнатурой. Эти числа описывают конфигурацию
метаданных; они не доказывают качество кадра, выбор целей, скрытие в тумане,
повтор события или звук.

Для каждой строки я сравнивал `kind`, `target`, форму/радиус области, тип урона,
состояния, длительность и смысл описания с `visualProfile.family`, `cue.kind` и
ветками 2D/3D renderer. Наиболее заметный воспроизводимый остаток: вся семья
`mobility` получает в 2D общее кольцо, подпись школы и generic glyph без знака
направленного движения. В 3D для той же семьи уже есть `mobilityArc`, поэтому
2D и 3D расходятся по смыслу. Patch-кандидат добавляет восходящую стрелу в 2D
и фиксирует тот же восходящий жест через apex в 3D. Механика, target validation,
ресурс и события не меняются.

## Источники и критерий BG3

Ключевые карточки источника, использованные для проверки коллизии:

- [Скороход / Longstrider](https://www.dnd.su/spells/316-longstrider/): касание,
  +10 футов скорости на час, дополнительные цели при усилении.
- [Прыжок / Jump](https://www.dnd.su/spells/286-jump/): касание, расстояние
  прыжка увеличивается втрое на минуту.
- [Поспешное отступление / Expeditious Retreat](https://www.dnd.su/spells/257-expeditious-retreat/):
  на себя, концентрация, Dash при наложении и бонусным действием в следующие ходы.
- [Ускорение / Haste](https://www.dnd.su/spells/100-haste/): согласная цель,
  удвоение скорости, +2 КД, преимущество на Dex saves и дополнительное действие.
- [Полёт / Fly](https://www.dnd.su/spells/249-fly/): отдельная скорость полёта
  60 футов и падение после окончания эффекта.
- Для контраста: [Множественное лечение ран](https://www.dnd.su/spells/171-mass-cure-wounds/),
  [Защита от энергии](https://www.dnd.su/spells/106-protection-from-energy/) и
  [Щит](https://www.dnd.su/spells/70-shield/) требуют разных акцентов: массовая
  волна к выбранной точке, выбранный тип сопротивления и реакционный невидимый
  барьер соответственно.

В официальных заметках Larian к [Patch 5](https://forums.larian.com/ubbthreads.php?Number=780440&page=all&ubb=showflat)
записаны уникальные VFX для классовых заклинаний, согласование визуалов общих
заклинаний между классами и отдельная обратная связь о невозможной цели. В
[Patch 6](https://forums.larian.com/ubbthreads.php?Number=792764&ubb=showthreaded)
Larian описывает разные материальные образы: энергетическую сферу Chromatic Orb,
защитное облако летящих кинжалов Cloud of Daggers и изменение размера у
Enlarge/Reduce. Это хороший ориентир: семейство может иметь общий материал и
палитру, но форма, направление, область и состояние должны быть читаемы.
[Официальный press kit Larian](https://larian.com/press) использован как источник
первичных gameplay/materials, а не как доказательство конкретного кадра.

## Исправление-кандидат

Patch находится в `%TEMP%\skazanie-agents25\24\mobility-family-visual.patch`.
Он меняет только два renderer-файла:

- `src/spell-effects.ts`: для `family === 'mobility'` добавляется компактная
  восходящая стрелка из двух штрихов. Она видна в канале Longstrider/Jump/
  Expeditious Retreat вместо общего семейного квадрата/пустого glyph.
- `src/board3d-spell-effects.ts`: mobility line получает общий с 2D apex,
  поэтому 3D показывает тот же жест «вверх/вперёд», а не купол или случайную
  декоративную дугу.

Это намеренно маленький presentation-only patch: он не присваивает механику
неподдержанным заклинаниям, не меняет target selection, event schema, звук,
ресурсы или persistent effects.

Тест-кандидат: `%TEMP%\skazanie-agents25\24\mobility-family-visual.test.mjs`.
Он проверяет именно наличие направленного 2D glyph и общего 3D apex, а не
метаданные. На исходном дереве оба теста ожидаемо красные. После применения
patch к изолированной копии (`%TEMP%\skazanie-agents25\24\staged`) результат:

```text
✔ mobility has a directed 2D glyph
✔ mobility keeps the same upward gesture in 3D
tests 2, pass 2, fail 0
```

Фактический запуск:

```text
node --test %TEMP%\skazanie-agents25\24\mobility-family-visual.test.mjs
```
