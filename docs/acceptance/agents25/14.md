# Исполнитель 14 — компонент A и источники магии

Статус: patch-кандидат для дефекта источника Magic Initiate; приёмка не
заявляется. База задания — c4e570921edea08f8952edef7c437bc5c9182ab3.

## Источники и границы

Проверены карточки [Magic Initiate](https://5e14.dnd.su/feats/133-magic-initiate/),
[волшебника](https://5e14.dnd.su/class/105-wizard/) и
[заклинательной фокусировки](https://5e14.dnd.su/articles/mechanics/157-spellcasting/).
Черта требует выбрать класс и даёт заклинания именно из его списка; выбранная
школа определяет характеристику. Карточка черты не даёт бойцу умение
Spellcasting или право использовать фокус волшебника. Фокус доступен только
через настоящее классовое умение; для волшебника его карточка отдельно говорит,
что магическая фокусировка используется для заклинаний волшебника. Для M без
цены у бойца остаётся компонентная сумка. [Sage Advice](https://5e14.dnd.su/articles/mechanics/318-sage-advice-compendium/)
разрешает фокус только для M без цены и без расходования; это не создаёт
Spellcasting feature у персонажа, взявшего черту.

Отдельно сверены карточки [Jims Magic Missile](https://5e14.dnd.su/spells/2341-jims-magic-missile/),
[Gift of Gab](https://5e14.dnd.su/spells/1922-gift-of-gab/) и
[Jims Glowing Coin](https://5e14.dnd.su/spells/2340-jims-glowing-coin/).
Источник требует оплату авторских отчислений даже при применении через свиток
или другой магический предмет; при нехватке денег заклинание не тратится, но
наложение невозможно. Исправление разбора A для этих трёх ID уже есть в
PR #85 и повторно не делалось.

Текущий runtime пока не исполняет эту оплату: spellComponentAvailabilityFor
возвращает SPELL_SPECIAL_COMPONENT_UNSUPPORTED, события оплаты нет; предметный
путь существует только для жезла magic-missile, общего пути свитка нет.
Это отдельная зависимость для следующей поставки, а не заявленный результат
этого patch.

Сверка источников применения:

- обычный герой выбирает spell_slots_N; колдун использует pact_slots и
  mystic_arcanum_6, а явно переданный недоступный ресурс отклоняется;
- innateSpell получает species_spell_ID и при исчерпании ограниченной выдачи
  может перейти на class/fallback resource, но выбранный класс Magic Initiate
  терялся до этого patch;
- generic scroll source в текущем каталоге и CastSpell отсутствует;
- предметная магия отделена от CastSpell: поддержан только
  wand-of-magic-missiles, он не расходует обычную ячейку и не имеет A;
- для обычного CastSpell проверка компонентов выполняется до выбора ячейки,
  а ItemConsumed и ResourceSpent собираются только после успешной валидации;
  это сохраняет атомарный отказ для существующих M-компонентов.

## Подтверждённый дефект

resolvePhbCreation и character-build создавали выдачу Magic Initiate без
class_key. Затем combatSpellsFor собирал её как innateSpell, но не сохранял
выбранный класс как metadata. Для реального волшебника это теряло связь
выбранного класса с его настоящим Spellcasting feature. Для бойца с той же
чертой фокус, наоборот, не должен открываться. База даёт:

  spell.spellcastingClass === undefined
  spellComponentAvailabilityFor(...) === { available: false, code: 'SPELL_MATERIAL_COMPONENT_REQUIRED' }

То есть metadata выбранного класса теряется. Patch сохраняет её отдельно и
выставляет effective spellcastingClass только когда реальный class profile
совпадает с выбранным классом. Боец с wand получает отказ, боец с component
pouch проходит, а волшебник с тем же выбранным классом и wand проходит.
Административная выдача не использовалась как доказательство.

## Patch и тест-кандидат

Предложенный patch сохраняет class_key в PHB-выдаче и выдаче черты при
развитии, хранит его как innateSpellcastingClass и переносит в effective
spellcastingClass только при наличии настоящего совпадающего class profile.
Механика оплаты, статусы карточек и общий Rules Engine не разблокируются.

## Браузерный сценарий

Для отдельной копии запускались сервер на http://127.0.0.1:8920, Vite на
http://127.0.0.1:4199, пустой ROUTERAI_API_KEY и хранилище
C:\Users\anton\AppData\Local\Temp\skazanie-agents25\14-browser-storage.
В комнате A14FOCUS обычный мастер прошёл выборы: Fighter → Variant Human →
Sage → Magic Initiate → Wizard. На экране выбора заговоров были видны
«Малая иллюзия» и «Сообщение», а карточка черты показывала правило выбранного
класса.

Фактический blocker: после перехода к выбору заговоров страница показывала
«Нет связи с сервером», поэтому клик по M-заговору не дал подтверждённого
исхода. После сброса CUA браузерная сессия стала недоступна. Абсолютный путь
кадра API CUA не вернул: screenshot был доступен только inline, файл кадра не
создавался. Обычный пользовательский сценарий поэтому оставлен
непринятым; patch подтверждён только исполнимым тестом в Temp-копии.
