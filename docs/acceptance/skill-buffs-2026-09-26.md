# Навыковые баффы: приёмка 2026-09-26

Кандидат из `%TEMP%/skazanie-spells-finish/skill-buffs` интегрирован root
26 сентября. Ниже сохранены его профильные проверки; объединённый результат
фиксируется в [журнале партии](spell-finish-2026-09-26.md).

Источник 2014 для [«Заимствованных знаний»](https://www.dnd.su/spells/3938-borrowed-knowledge/):
книга стоимостью не менее 25 зм, один выбранный навык без владения, один час,
без концентрации. Компонент не расходуется. Для [«Усиления навыка»](https://www.dnd.su/spells/494-skill_empowerment/)
зафиксированы касание согласной цели, уже освоенный навык без Expertise,
удвоение бонуса мастерства на час и концентрация.

Патч делает следующее:

- `skillProficiencyForActor(actor, skill, state)` учитывает временное владение и
  удвоение в том же месте, которым пользуются `MakeAbilityCheck`, пассивные
  проверки, серверные проверки объектов и свободное действие.
- `Borrowed Knowledge` требует серверно подтверждённую книгу от 25 зм,
  добавляет временное владение выбранным навыком на 60 минут, заменяет свой
  старый выбор при повторном наложении и не создаёт `ItemConsumed`.
- `Skill Empowerment` требует владение без Expertise, допускает только одну
  активную ступень удвоения и связывает условие с концентрацией заклинателя.
  Согласие не берётся из недоверенного поля команды: используется существующая
  серверная семантика цели `ally`, как у остальных контактных усилений.
- Новые условия имеют явный `skill_buff_version: 1`,
  `timing_version: 2` и секунды мировых часов (`expires_at_seconds`);
  при истечении `Skill Empowerment` очищаются и условие, и запись концентрации.
  Старые похожие строки без маркера не получают механического смысла.
- Цена книги берётся из серверного PHB purchase catalog (`book` = 25 зм,
  `spellbook` = 50 зм); произвольные `name`/`type`/`price_cp` из инвентаря
  компонентом не становятся.
- `spellOptions` в override дают обычному выбору заклинания 18 навыков, а
  `DungeonMap` показывает их русскими названиями; допустимость конкретного
  выбора всё равно решает Rules Engine.

Статус обоих override — `partial`: серверная механика закрыта, но отдельный
сквозной HTTP/UI receipt-сценарий ещё не заявляется как подтверждённый.
