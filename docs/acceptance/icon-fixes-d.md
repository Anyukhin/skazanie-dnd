# Приёмка точечных замен spell icons — `mislead` и `programmed-illusion`

Дата: 2026-09-26. Исправлены только два runtime-файла:

- `public/assets/ui/action-icons/mislead.png`;
- `public/assets/ui/action-icons/programmed-illusion.png`.

Причина замены — предыдущие иконки были слишком общими: `mislead` показывал
один призрачный силуэт в медальоне, а `programmed-illusion` — декоративный шар
на подставке без видимой иллюзорной сцены и программируемого триггера.

## Генерация и промпты

Использован встроенный ImageGen в режиме генерации нового прозрачного bitmap
(не CLI/API). Общая стилистическая рамка для обоих вариантов: hand-painted
dark-fantasy fantasy tabletop RPG inventory icon, polished painted 3D asset,
weathered bronze/iron/leather, warm rim light, dark carved contours, restrained
old-master palette, один ясный фиолетово-синий магический акцент, прозрачный
фон, компактный силуэт, читаемость в 32 px, без текста, рамки, медальона,
плитки, watermark, pseudo-text, neon glyph и glossy plastic.

### `mislead`

Точный смысловой запрос: «Показать ровно две отдельные гуманоидные фигуры:
непрозрачную тёмную фигуру в капюшоне слева и явно отделённого исчезающего
полупрозрачного иллюзорного двойника справа; двойник растворяется в
фиолетово-синих магических фрагментах. Пара должна сразу читаться как обман,
невидимость и ложный двойник. Не использовать круговую рамку, амулет,
постамент, дополнительные персонажи, оружие или unrelated object».

Результат ImageGen: `tmp/icon-fixes-d/raw/mislead.png`, SHA-256
`e62635d28f71540cbf92f9f6049e463e407fabb919b7e26d81c0c9aedf48cc1d`,
1254×1254.

### `programmed-illusion`

Точный смысловой запрос: «Показать один тёмно-фэнтезийный латунный проектор
иллюзий, который над линзой проецирует отчётливую полупрозрачную мини-сцену
с гуманоидной фигурой; на корпусе должен быть небольшой встроенный
часовой/шестерёнчатый триггер и циферблат, обозначающий запрограммированное
условие. Визуальным фокусом остаётся проекция. Не использовать декоративные
песочные часы, одиночный общий шар, полный текст, надписи или unrelated
objects».

Результат ImageGen: `tmp/icon-fixes-d/raw/programmed-illusion.png`, SHA-256
`4f3a522373f3f74eecf97254589b0a3548ecd5951df09f284a6c512c72d97f64`,

Оригиналы сохранены для восстановления в `tmp/icon-fixes-d/original/`:

## Подготовка runtime

Прозрачные исходники прошли существующий проектный `tmp/icon-all/normalize_icon.py`
с alpha64-longest около 435 px и затем были уменьшены Pillow Lanczos до
256×256 RGBA. Staging-файлы оставлены в `tmp/icon-fixes-d/`:

- `final-512/mislead.png`: 512×512, SHA-256 `5ae7e9768eb5810d20425f272ae284df7b198134928f941c2222ac95dc343e48`;
- `final-512/programmed-illusion.png`: 512×512, SHA-256 `0519c150478923c47da6133e1d7a81b76c87d61bd725b62ceb193b2a19885d50`;
- `final-256/mislead.png`: 256×256 RGBA, SHA-256 `8a3fcf2830365aecea4142d0203d06b473351d40293fdb82121859435c82e81c`;
- `final-256/programmed-illusion.png`: 256×256 RGBA, SHA-256 `3089af72233eb655bc6c6b935d2265b58889c0378b0b695a34e894abff3e502a`.

Финальная визуальная проверка установленных файлов показала:

- `mislead`: два отдельных читаемых силуэта, один непрозрачный и один
  полупрозрачный с распадом по правому краю; амулета и рамки нет;
- `programmed-illusion`: над латунным проектором видна сцена с фигурой,
  на корпусе читаются шестерёнка и триггерный циферблат; декоративного
  песочного шара нет;
- оба файла: 256×256, режим RGBA, alpha extrema `0..255`, угловая alpha
  максимум `0`, то есть фон действительно прозрачен.

`data/asset-rights.json` и другие файлы реестра намеренно не изменялись:
регистрация SHA оставлена для root после визуальной приёмки.
