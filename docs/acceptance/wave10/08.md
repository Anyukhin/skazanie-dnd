Интеграция 26 сентября: код перенесён в рабочую ветку и доработан после независимого review. Актуальные объединённые проверки — в [журнале партии](../spell-finish-2026-09-26.md). Ниже сохранён первоначальный отчёт кандидата; его Temp-патч не применять повторно.

## Источник и границы

Карточка [dnd.su для «Разрушительной волны»](https://5e14.dnd.su/spells/296-destructive-wave/)
задаёт 5-й круг, действие,
«на себя (30-футовый радиус)», выбор существ, спасбросок Телосложения,
5к6 громом и 5к6 излучением или некротической энергией по выбору
заклинателя; при провале цель падает ничком, при успехе получает половину
урона. Законный источник доступа в проекте — [жрец](https://5e14.dnd.su/class/89-cleric/)
9-го уровня с подклассом `tempest`; ручной grant паладину источником не
считается.

Patch добавляет полную доменную таблицу Tempest с парами 1/3/5/7/9,
передаёт доменные пары по уровням в PHB benefits и раскрывает их в
`combatSpellsFor` только для `cleric/tempest`. `destructive-wave` остаётся
`mechanicsSupport: partial` с явным `supportNote`: серверный handler покрывает
выбор целей, центр self-area, радиус, Con save, typed mixed damage, половину
при успехе, prone при провале, resistance/immunity, reaction/lifecycle и NPC
bridge; обычный player UI/VFX/CUA acceptance остаётся внешним этапом.

## Серверные проверки

Self-area принимает только непустой явно переданный `target_ids`; дубликаты,
неживые, отсутствующие, удалённые из области и находящиеся дальше 30 футов
цели отклоняются до расхода ячейки. Автоматический выбор союзников или врагов
не выполняется, заклинатель может выбрать себя. Для NPC selection path использует
тот же area owner, затем `npcHarmEventDrafts` сохраняет обе typed components и
применяет resistance к каждой части до последовательного уменьшения HP.

Обе части урона используют один elemental reaction key на цель и заклинание;
выбранная реакция absorb применяется только к triggering damage type. Replay
сохраняет два `DamageApplied`/один consequence и не создаёт концентрацию.
