## Источник и граница

Карточка [«Обессиливание» на dnd.su 5e14](https://5e14.dnd.su/spells/486-enervation/)
задаёт одно действие, 60 футов и концентрацию до минуты. При успехе спасброска
цель получает отдельные 2к8, при провале — 4к8; при провале заклинатель может
действием повторять 4к8 по той же цели. Заклинание заканчивается, если
заклинатель использует действие для другого поступка, цель выходит из 60 футов
или получает полное укрытие. Каждый фактически нанесённый некротический урон
лечит заклинателя на половину; усиление даёт 1к8 за каждый круг ячейки выше
пятого.

## Что изменено

- Override получает server-owned continuation profile с action id
  enervation-repeat, исходной целью, дальностью, некротическим уроном,
  upcast и лечением по фактически нанесённому урону.
- Первичный урон при успешном и провальном спасброске лечит так же, как
  повторный. Для lifesteal учитываются applied_amount +
  temporary_hp_absorbed; поле applied_amount остаётся HP-компонентом
  DamageApplied.
- Связь хранит timing v2 на 60 секунд. После ActorMoved, AdvanceTime,
  выбытия цели или появления полного укрытия движок сам пишет
  ConcentrationEnded; ручной repeat больше не нужен для закрытия устаревшей
  связи. Одна лишь потеря раскрытия клетки связь не завершает, а EndTurn
  без расхода действия её не завершает.
- Действие появляется только из server-owned пары
  concentration.effect_id + enervated, сохраняет исходную цель и получает
  iconId: "enervation". UI должен направить этот alias в существующий
  enervation.png через manifest, без второго файла или 404.
- Сопротивление уменьшает lifesteal, иммунитет даёт нулевой урон и нулевое
  лечение; повтор не расходует ячейку или компоненты.

клетка без ложного конца, 60 секунд и обычное другое действие. Статус verified
остаётся pending до этого CUA и полного root gate.
