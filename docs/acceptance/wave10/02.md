## Контракт

- Клиент читает `CombatSpell.areaGeometryVersion`. Для пилотов это
  `circle-grid-v2`; отсутствие поля оставляет legacy `legacy-grid-v1`.
- Подтверждённый point-cast получает из server event
  `area_geometry_version` и `area_grid_origin`; reconnect battleLog читает
  `area.geometryVersion` и `area.gridOrigin`.
- Persistent projection читает `geometry_version` и `grid_origin`. При
  отсутствии версии старые области проходят прежнюю Chebyshev-ветку.
- `gridOriginForTargetCell` вычисляет NW-пересечение выбранной клетки. Клиент
  использует его только для предпросмотра и прицела; в команду `CastSpell` не
  добавляет радиус, версию или origin.

## Кандидат

Файлы и diff лежат в

- `src/area-geometry.ts` — ветка `circle-grid-v2` для sphere/cylinder через
  общий `circularAreaCells`; legacy путь сохранён.
- `src/types.ts` — версия профиля заклинания, event area и persistent metadata.
- `src/DungeonMap.tsx` — authoritative profile → preview geometry; один набор
  `previewBlastKeys` для 2D и 3D; active effects прокидывают metadata.
- `src/spell-targeting.ts`, `src/TacticalBoard.tsx`, `src/TacticalBoard3D.tsx` —
  прицел и координатная подсказка стоят на NW gridintersection для новой версии;
  renderer marker принимает `targetAnchor` и не сдвигает versioned endpoint на
  центр клетки.
- `src/spell-targeting.ts` использует общий `circularAreaLineOfEffect` для
  versioned preview mask и point trajectory; для point-cast проверяется
  доступность origin области от любой клетки footprint заклинателя с радиусом
  600 ft и `spreadsAroundCorners: false`, как в Rules Engine. Legacy сохраняет
  прежний `hasClearBoardTrajectory`.
- `src/board-render.ts`, `src/tactical-ui.ts` — persistent/difficult-terrain
  footprint использует ту же геометрию, legacy остаётся прежним.
- `src/combat-animation.ts`, `src/spell-effects.ts` — metadata проходит через
  SpellCast, battleLog, SpellAreaCreated и persistent renderer, поэтому 2D/3D
  подтверждённого эффекта используют один footprint. Burst center в 2D flight и
  3D Fireball/area ring для `circle-grid-v2` рисуется без скрытого `+.5`.
- `src/combat-spells.ts` — fallback не переносит `areaGeometryVersion` в старый
  ruleset; metadata остаётся доступной только для source-backed 2014 projection.
- `server/circular-area-geometry.d.mts` — копия декларации API №01 для
  изолированной проверки кандидата; production владеет этим файлом №01.
- `patches/harness-flat-output-isolation.patch` — перевод оставшихся семи
  flat-output harness, транзитивно компилирующих `board-render.ts`, на
  изолированные `buildDir/src` и `buildDir/server` через `--rootDir`.
