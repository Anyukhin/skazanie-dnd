# `server/` — замороженная JS-библиотека

**Это не сервер.** Сервер игры — Rust (`rust/`, бинарь `skazanie-server`);
прежний JS-сервер с 2026-11-27 в архиве (`archive/js-server/README.md`).

Здесь остались модули, которые до сих пор читает живой код:

- **клиент** (`src/`) — восемь модулей: размер фигурки, варианты классов и
  черт при создании героя, геометрия круговых областей, причины конца
  концентрации, вид снаряжения, выход отряда, сюжеты кампаний;
- **инструменты контента** (`tools/`) — `content:verify`, `spells:verify`,
  `maps:preview`, `models:scale` и другие читают каталоги и генераторы отсюда;
- **стенды** (`eval/`) — бот Асстохана и бои через HTTP строят героев и
  планируют ходы правилами отсюда, а играют против бинаря Rust;
- **контрактные тесты** (`test/contract-rust.list`) — собирают состояния и
  ожидания этими же правилами;
- **Rust-тесты** — `spell_override_audit` включает `rules-engine.mjs` в сборку,
  сторожа реестров (`prompt_descriptors`, онтология мира, причины конца
  концентрации) читают исходники отсюда и из архива.

## Правила

- Новое поведение игры — только в `rust/`. Правка здесь в игру не попадает.
- Модуль правится, только если этого требует клиент или инструмент; тогда то
  же поведение — в Rust, в той же ветке.
- Модуль, который больше никто не читает, уходит в `archive/js-server/server/`.
- `// @ts-check` в первых строках — наследство прежней проверки
  `typecheck:server` (в архиве); сейчас эти файлы ничем не проверяются.
